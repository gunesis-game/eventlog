# Engineering Standards

This directory holds the generic engineering standards. Project-specific choices live under `docs/project/` and link here instead of copying a standard.

| Standard | Governs | Project-specific companion |
|---|---|---|
| [Coding Standard](coding.md) | Code organization, naming, implementation conventions, maintainability, and architectural alignment | [Architecture](../project/architecture.md) |
| [Testing Standard](testing.md) | Test design, test levels, architecture-aware selection, feedback tiers, gates, and evidence | [Testing strategy](../project/testing-strategy.md) |
| [Performance Engineering Standard](performance-engineering.md) | Workloads, metrics, baselines, targets, benchmark quality, regression analysis, and evidence | [Performance strategy](../project/performance-strategy.md) |
| [Git Workflow Standard](git-workflow.md) | The main-only rule (no other branches), commits, CI evidence, workflow-run retention, and recovery | The standard's [project policy](git-workflow.md#project-policy) section and [commands](../project/commands.md#ci) |

When adding a standard, add it to this index.
